# Inndeavor codex教程

面向销售、CM 和店长的 Codex 入门培训：看完下载安装与基础使用视频，每人选一题，完成首次任务、继续修改和文件核查。

**网页入口：[Inndeavor codex教程](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)**。领导和同事可直接打开，也可下载仓库 ZIP 离线使用。

## 本次学什么

按视频完成安装和登录，打开 Codex，提供资料并说清目标；请它保存成果文件，在同一对话修改一次，打开文件对照素材核查。每题都有首次指令和修改指令参考，可以用自己的话说。

培训以基础操作为通过条件，不要求写代码或使用高级工具。官方下载与当前入门入口见 [OpenAI 官方入门说明](https://developers.openai.com/codex/quickstart)。

## 岗位任务

| 岗位 | 可选题目 | 最终成果 |
| --- | --- | --- |
| 销售 | 客户话术 | 一份最终话术文字文件（.txt 或 .md） |
| 销售 | 周边介绍 | 一份交通、购物、生活三部分的介绍文字文件 |
| 销售 | 地图标注 | 基础：标注方案文字文件＋原地图；选做：标注后的地图图片 |
| 销售 | 房源图片优化 | 基础：优化方案文字文件＋原图；选做：原图与优化图对照 |
| CM | 催租与付款核对 | 一份沟通文字文件，含回复及待核实事项 |
| CM | 事务准备 | 一份入住准备清单文件（文字或表格均可） |
| 店长 | 空置房源决策 | 一份最终比较表文件，含费用明细、预计收入、净额、建议及一句下一步 |

每人只做本岗位的一题。地图与照片基础交方案文件，实际图片处理选做；店长先做 3 周比较，再改为 5 周，额外情景和临界天数选做。

## 员工怎么用

1. 观看[培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)，完成安装和登录。
2. 打开培训网页，选岗位和一题，复制首次指令与素材。
3. 在 Codex 中新建任务并选择练习文件夹，发出指令，打开第一版文件。
4. 在同一对话提出具体修改，再打开最终文件核查，提交三项材料。

只交：**最终文件、自己在 Codex 中的首次与修改指令证据、两三句话的核查说明**。负责人按会交代任务、会继续修改、会核查与交付判断，均达到基本要求即可通过，允许修正后重交。页面自查仅保存在当前浏览器。

## 给领导展示

网页右上角“汇报导览”依次介绍培训目的、岗位实操、交付评阅和完成步骤。页面保留科技发布会风首页与互动培训卡片，支持手机、电脑和键盘；卡片房源线稿为视觉示意。

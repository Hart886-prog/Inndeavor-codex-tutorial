# Inndeavor codex教程

把 Codex 用进日常工作：每人在本岗位选择一题，交付一份可用、可核查的成果。

**网页入口：[Inndeavor codex教程](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)**。领导和同事可直接打开；也可下载仓库 ZIP 离线使用。

## 培训要解决什么

培训目标是让员工把 Codex 用在日常工作中，能交代任务、做出成果、提出修改并核查依据。销售、CM 和店长各在自己的岗位选择一题，保持入门门槛。

题目覆盖销售客户沟通、CM 事务准备和店长利润管理，共 7 道可选题、35 条模拟素材。考试重点是员工能否把要求说明白、看懂结果、提出具体修改并对照资料核查。

## 给领导展示

打开网页后，点击右上角“汇报导览”，依次介绍培训目的、岗位实操、交付与评阅、完成步骤。最后一页可直接进入实操，演示岗位选择、素材原文、任务复制与文件下载。

网页采用科技发布会风首页和可轻微倾斜的培训卡片，支持电脑、手机和键盘操作；系统开启“减少动态效果”时静态显示。视觉示意不代表真实房源户型。

## 岗位题目

每人只做自己岗位的一题，不要求完成全部题目。

| 岗位 | 任务选择 |
| --- | --- |
| 销售（四选一） | 客户话术、周边介绍、地图标注、房源图片优化 |
| CM（二选一） | 催租与付款核对、事务准备（入住／退租／查房） |
| 店长（一项） | 利润管理：计算管理经营结果、分析原因、提出两条建议 |

## 员工怎么用

1. 先观看[参考培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)。
2. 打开[培训网页](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)。离线使用时，在 GitHub 点击 **Code → Download ZIP**，解压后用浏览器打开 **index.html**。
3. 选择岗位及一项任务，领取素材，使用 Codex 制作、修改并核查成果。
4. 提交下面三项材料，交由负责人评阅。

## 交什么，如何评阅

- 成果文件：按所选题目的形式交付，图片或地图保留原件及修改后的对照。
- 指令证据：首次任务指令和一次具体修改指令的截图或文字。
- 核查说明：2—3 句话说明核对了什么、修改了什么、仍有什么待确认。

负责人按“资料准确、成果可用、会修改和核查”三项判断，均达到基本要求即可通过；有问题允许修改后重交。不按提示词长度、特效数量或排版精美程度排名。

页面的自查只记录当前浏览器中的进度，不能代替负责人评阅，也不是在线成绩记录。

## 文件与使用边界

- [index.html](./index.html)：交互挑战页面，内含题目、模拟资料、复制与下载功能，可独立打开。
- [培训说明.md](./培训说明.md)：培训流程、完整题干、交付示例和评阅标准。

所有示例房源、客户、租客及金额均为培训模拟。地图题使用真实地址及对应地图截图，图片题使用房源原图；均须使用获准素材，缺素材可换题。

店长题按管理经营口径计算，结果不称公司净利润或现金回款；欠租另列收款风险，不重复扣减。

# Inndeavor codex教程

面向 INNDEAVOR 员工的 Codex 入门培训与岗位实操挑战。每人在本岗位只选一题。

## 使用方式

1. 先观看[参考培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)。
2. 在 GitHub 点击 **Code → Download ZIP**，解压后用浏览器打开 **index.html**。
3. 选择岗位及一项任务；领取素材，使用 Codex 制作、修改并核查成果。
4. 提交成果文件、首次与修改指令、2—3 句话的核查说明。

| 岗位 | 任务选择 |
| --- | --- |
| 销售（四选一） | 客户话术、周边介绍、地图标注、房源图片优化 |
| CM（二选一） | 催租与付款核对、事务准备（入住／退租／查房） |
| 店长（一项） | 利润管理：计算管理经营结果、分析原因、提出两条建议 |

页面可独立打开，无需安装软件或启动服务器。自查进度保存在当前浏览器，不是在线成绩记录。上传仓库不代表已发布在线网站。

## 文件

- [index.html](./index.html)：交互挑战页面，内含题目、模拟资料、复制与下载功能。
- [培训说明.md](./培训说明.md)：完整题干、提交要求和评阅标准。

所有示例房源、客户、租客及金额均为培训模拟。地图和图片题需使用获准的真实素材；缺素材可换题。

店长题按管理经营口径计算；结果不称公司净利润，欠租另列为收款风险。

当前为培训样稿，新题待员工试做。实际教学时长以试做结果为准。

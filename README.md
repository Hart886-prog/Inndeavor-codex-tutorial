# Inndeavor codex教程

**[打开负责人实战网页](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)**

面向销售负责人、CM 负责人和店长，让 Codex 搭建可反复使用的工作工具，练习多表关联、数据核对、异常处理与换数据更新。

| 岗位 | 实战题 | 最终交付 |
| --- | --- | --- |
| 销售负责人 | 小红书广告工作台 | 可启动的工作台与源文件，附广告输出、发布队列和一次数据变更测试 |
| CM负责人 | 欠款核对工作台 | 可启动的核对工具与源文件，附对账明细、异常清单和一次更新测试 |
| 店长 | 空置决策工作台 | 可启动的决策工具与源文件，附逐套明细、异常清单和一次假设变更测试 |

## 如何开始

观看[基础培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)，完成安装和登录；[官方下载与入门](https://developers.openai.com/codex/quickstart)。打开网页领取岗位题，下载 CSV 到练习文件夹，复制搭建指令给 Codex；自己运行、核查并提出修改，用更新数据验证复用。

## 交付和评阅

交可运行工具包及启动说明、原始与更新输入输出对照、首次与修改指令及核查说明。按 **工具能跑、数据可靠、换数据可复用** 评阅，允许修正后重交。页面勾选仅为个人自查，不是成绩或负责人验收。

3 道工具题、7 份可导入 CSV、15 组资料和规则；所有房源、租客、金额和发布记录均为模拟。小红书真实发布需先核实可用入口和账号；未接通注明待接入，演练不能当作实际发布。当前公开授权范围不保证发布接口可用，见[小红书官方文档](https://openaccount.xiaohongshu.com/docs/scope)。

## 文件与离线使用

- [index.html](./index.html)：独立页面，内含完整题库、CSV、复制及下载功能。
- [培训说明.md](./培训说明.md)：完整题干、搭建指令、规则、数据和验收实例。

离线：GitHub **Code → Download ZIP**，解压后打开 index.html。给领导展示可使用右上角汇报导览。界面沿用原科技发布会风，手机、电脑和键盘可用。

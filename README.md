# Inndeavor codex教程

**[打开日常工作实操页](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)**

用你正在使用的工作资料，交给 Codex 整理今天能用的结果。要求已经写好，直接复制；资料更新后再整理一次，保存方法，下次继续用。

| 岗位 | 用现有资料 | 拿到当天能用的结果 |
| --- | --- | --- |
| 销售 | 房源表和已有图片 | 一批小红书待发广告 |
| CM | 欠租表 | 跟进名单和对应提醒文字 |
| 店长 | 一套实际空置房源资料 | 持有与退还比较，或明确的待补清单 |

## 怎么做

观看[基础培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)，打开Codex。先提供本岗位工作文件或获准副本，再复制网页中的要求。对照原资料核查结果，再提一次具体修改：有近期真实更新就按新资料调整，没有就改排序或表达，业务事实保持正确。真实资料留在获准使用环境，不上传公开培训网页。

交一份岗位成果、一张修改对照、一句使用说明。按当天能用、依据正确、修改后还可用评阅，不强制做网页，不要求写技术说明。销售整理待发广告，负责人核对后自行发布。

[index.html](./index.html) 为独立培训页；[培训说明.md](./培训说明.md) 含完整任务、口语要求和提交示例。离线可下载仓库ZIP，解压后打开index.html。

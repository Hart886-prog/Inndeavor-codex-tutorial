# Inndeavor codex教程

**[打开小工具练习页](https://hart886-prog.github.io/Inndeavor-codex-tutorial/)**

每人选本岗位的一题，复制一句话给 Codex，让它做一个小页面。自己双击打开试用，再请它改一处。

| 岗位 | 做什么 | 怎么试 |
| --- | --- | --- |
| 销售 | 小红书广告小助手 | 填信息，生成并复制广告 |
| CM | 催租提醒小助手 | 选租客，生成并复制提醒 |
| 店长 | 空置房源小计算器 | 把3周改成5周，看建议变化 |

## 怎么开始

先观看[培训视频](https://www.xiaohongshu.com/discovery/item/6a080fda000000003502d325)，完成安装和登录。网页里已经写好要求和模拟资料，点击“复制这段话发给 Codex”即可。

让 Codex 把成果保存成 .html 网页文件并告诉你位置；双击打开，用浏览器查看。遇到打不开或按钮没反应，直接请 Codex 修好。

## 交什么

一个网页文件、一张实际效果截图、一句话修改说明。负责人只看：**能打开、主要功能能用、改过一处**。允许修好后重交。页面勾选是个人自查，不是成绩。

[index.html](./index.html) 为独立练习页面；[培训说明.md](./培训说明.md) 包含三题要求、资料和提交例子。离线可下载仓库 ZIP，解压后打开 index.html。所有人物、房源和金额均为模拟。
